## إعداد الأدوات

المهارات تحدد _كيف_ تعمل الأدوات. هذا الملف لـ _تفاصيلك_ — ما يميز إعدادك.

### ماذا يوضع هنا

أضف ما يساعدك في عملك. هذه ورقة غش خاصة بك.

مثل:

- مضيفي SSH والأسماء المستعارة
- إعدادات أخرى متعلقة بالمستخدم عند تنفيذ المهارات

### أمثلة

```markdown
### SSH

- home-server → 192.168.1.100، المستخدم: admin
```
